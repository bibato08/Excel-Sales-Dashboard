# 📊 Sales Dashboard – Excel

## 📌 Project Overview

This is my first interactive Sales Dashboard created using Microsoft Excel.

The dashboard was developed to analyze sales performance and present key business insights in an easy-to-understand visual format.

## 📂 Dataset

The dataset contains sales-related information such as:

* Order ID
* Date
* Region
* Sales Channel
* Customer Type
* Product Category
* Product
* Salesperson
* Quantity
* Unit Price
* Discount
* Revenue

## 📊 Dashboard Features

* Sales performance analysis
* Revenue analysis
* Regional sales analysis
* Product category analysis
* Sales channel analysis
* Customer type analysis
* Interactive PivotTable-based analysis

## 🎯 Objective

The main objective of this project is to transform raw sales data into an interactive Excel dashboard that can help understand sales performance and identify useful business insights.
